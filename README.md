# XYLINK WEBRTC MEETINGKIT REACT SDK

小鱼易连 WebRTC MeetingKit React Demo 项目

此项目使用到的技术栈：React+tailwind+Typescript

## 准备工作

1. 在 `src/utils/config.ts` 中配置默认值：

- clientId
- clientSecret
- extId
- SERVER

2. 更新配置可以在首页 -> 设置 -> 服务器 中设置；

## 运行

### 安装依赖

```bash
npm install
```

### 运行

```bash
npm run dev
```
